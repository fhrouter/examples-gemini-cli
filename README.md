# Free Gemini CLI Setup — FHRouter

Point [Gemini CLI](https://fhrouter.com/docs/guides/gemini) at FHRouter with two environment variables.

> **Free tier:** frontier AI models (Grok, DeepSeek, GLM) free on every [FHRouter](https://fhrouter.com) account — no credit card. [Free LLM API](https://fhrouter.com/free-llm-api) · [How free models work](https://fhrouter.com/docs/free-models)

## Setup

1. Create `.env` in the Gemini CLI config directory (see [`.env`](.env) in this repo) with your FHRouter key from https://fhrouter.com/token.
2. Run `gemini` and send a test message.

Full guide with troubleshooting: [https://fhrouter.com/docs/guides/gemini](https://fhrouter.com/docs/guides/gemini).

The gateway serves the Gemini wire API at `https://fhrouter.com/v1beta`; the [free tier](https://fhrouter.com/free-llm-api) also includes frontier models like `grok-4.6` on every account.
