# Gemini CLI with FHRouter

FHRouter provides access to Claude, GPT, and Gemini models through one API key and a prepaid balance. Check the [current catalog](https://fhrouter.com/pricing) for model availability, supported endpoints, and prices. Requests use your account balance; these examples do not include free inference.

Use [.env.example](.env.example) as a template for your local Gemini CLI environment. Replace `YOUR_FHROUTER_KEY` with your FHRouter key and select a Gemini model from the catalog. Follow the [Gemini CLI setup guide](https://fhrouter.com/docs/guides/gemini) for configuration and troubleshooting.

Never commit your real `.env` file. The example uses the Gemini-native endpoint at `https://api.fhrouter.com/v1beta`.
